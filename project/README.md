# Путеводитель по Москве

## Описание
Сайт-путеводитель по Москве, содержащий информацию о 12 достопримечательностях, встроенные карты, таблицу времени в пути, генератор случайного места и маршрута на выходные, а также раздел отзывов.

## Технологии
- HTML5
- CSS3 (Flexbox/Grid, медиазапросы)
- JavaScript (ES6)

## Функциональность
- [x] Адаптивный дизайн
- [x] Карточки достопримечательностей
- [x] Встроенные Яндекс.Карты
- [x] Таблица времени в пути
- [x] Построение маршрута
- [x] Генератор случайного места
- [x] Генератор маршрута на выходные
- [x] Раздел отзывов с сохранением
